## 🎯 АРХИТЕКТУРА ПРОМПТ-СИСТЕМЫ

### Концепция последовательного углубления

Каждая идея проходит через **8 исследовательских этапов**, где результат предыдущего этапа становится контекстом для следующего. Это обеспечивает глубину и взаимосвязанность анализа.[^2]

```
Идея → [^1] Анализ рынка → [^2] Спрос и боли → [^3] Сообщества → 
[^4] Конкуренты → [^5] Прогноз → [^6] Стратегии → [^7] Технология → [^8] Клиенты
```

## ЧАСТЬ 1: ОБЪЕМ И ДИНАМИКА РЫНКА

Используя актуальные данные 2024-2025 гг., определи:

### 1.1 Размер глобального рынка
- **TAM (Total Addressable Market):** 
  - Текущий объем в USD (2024)
  - Методология расчета (bottom-up/top-down)
  - Географическое распределение (топ-5 регионов)
  - Источники данных (Statista, Gartner, IDC и др.)

- **SAM (Serviceable Available Market):**
  - Реалистичная доступная часть TAM
  - Ограничения (географические, регуляторные, технологические)
  - % от TAM с обоснованием

- **SOM (Serviceable Obtainable Market):**
  - Захватываемая доля в первые 3 года
  - Реалистичный сценарий для стартапа
  - Барьеры масштабирования

### 1.2 Исторический рост и прогнозы

| 2025 (прогноз) | | | |
| 2026 (прогноз) | | | |
| 2027 (прогноз) | | | |

### 1.3 Стадия развития рынка
Классифицируй рынок по модели жизненного цикла:
- [ ] Зарождение (Emerging) — < 5% проникновения
- [ ] Ранний рост (Early Growth) — 5-20% проникновения
- [ ] Ускоренный рост (Rapid Growth) — 20-50%
- [ ] Зрелость (Maturity) — 50-80%

### ЧАСТЬ 4: ЦЕНОВАЯ ПСИХОЛОГИЯ

#### 4.1 Price Anchoring
**Существующие якоря в сознании:**
- "I currently pay $X for [alternative]"
- "I expect this type of tool to cost $Y"
- "I can afford up to $Z"

**Откуда берутся:**
- Competitors' pricing
- Аналоги из других категорий
- Budget constraints

**Стратегия якорения:**
1. Показать **высокую** цену сначала (годовой plan)
2. Затем месячный кажется "доступным"
3. Или: сравнить со стоимостью **времени** ("Saves 10h/mo = $500 value")

#### 4.2 Willingness to Pay (WTP)

**Методы оценки:**
- Van Westendorp (4 вопроса):
  - "Too expensive" threshold: $X
  - "Getting expensive" threshold: $Y
  - "Good value" threshold: $Z
  - "Too cheap (suspicious)" threshold: $W

**Результаты из исследований:**
| Segment | WTP range | Sweet spot | Payment preference |
|---------|----------|-----------|-------------------|
| Students/Hobbyists | $0-$15/mo | $9/mo | Monthly |
| Professionals | $20-$100/mo | $49/mo | Annual (discount) |
| Teams | $100-$500/mo | $199/mo | Annual |

#### 4.3 Payment Friction

**Барьеры оплаты:**
| Barrier | % affected | Solution |
|---------|-----------|----------|

| Annual commitment fear | 55% | Monthly option |
| Currency conversion | 30% | Local pricing |

## ПРИМЕР ИСПОЛЬЗОВАНИЯ В КОДЕ

```

// lib/ai/comprehensive-analysis.ts

import { perplexityAnalyze } from './perplexity';
import { STAGE_PROMPTS } from './prompts';

export async function runComprehensiveAnalysis(idea: Idea) {
const results = {};

// Stage 1: Market Analysis
console.log('[Stage 1/8] Analyzing market...');
results.stage1 = await perplexityAnalyze(
STAGE_PROMPTS.STAGE1_MARKET.replace('{IDEA_TITLE}', idea.title)
);
await saveStageResult(idea.id, 'market', results.stage1);

// Stage 2: Demand Analysis (uses Stage 1 context)
console.log('[Stage 2/8] Analyzing demand...');
results.stage2 = await perplexityAnalyze(
STAGE_PROMPTS.STAGE2_DEMAND
.replace('{IDEA_TITLE}', idea.title)
.replace('{MARKET_ANALYSIS}', results.stage1)
);
await saveStageResult(idea.id, 'demand', results.stage2);

// Stage 3: Communities (uses Stage 1+2)
console.log('[Stage 3/8] Mapping communities...');
results.stage3 = await perplexityAnalyze(
STAGE_PROMPTS.STAGE3_COMMUNITIES
.replace('{IDEA_TITLE}', idea.title)
.replace('{STAGE1_2_CONTEXT}', results.stage1 + results.stage2)
);
await saveStageResult(idea.id, 'communities', results.stage3);

// ... Continue for stages 4-8

// Final: Executive Summary
console.log('[Final] Generating executive summary...');
const executiveSummary = await generateExecutiveSummary(results);
await saveStageResult(idea.id, 'executive_summary', executiveSummary);

// Update idea status
await db.query(
'UPDATE ideas SET status = \$1, analysis_completed_at = NOW() WHERE id = \$2',
['analyzed', idea.id]
);

return {
idea_id: idea.id,
stages: results,
executive_summary: executiveSummary
};
}

```
